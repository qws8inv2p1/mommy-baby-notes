# 尊医重卫 护佑生命｜市一医院八名医师荣获首届“仁心匠心医师”

> 更新时间：2026-09-16 (UTC+8)

//  

奋进新时代、建设新天堂。为庆祝第五个“中国医师节”，弘扬“大医精诚 仁心仁术”的医者精神，选树“仁心匠心医师”典型，以“仁心”温 暖病患，以“匠心”解除病痛，激励更多职工“学习好榜样、 传递正能量”，8月17日下午，市宣文卫工会联合西泠印社集团，在西泠印社美术馆举办杭州市宣文卫工会首届“仁心匠心医师”认定发布活动。

杭州市第一人民医院**朱瑾、朱英、王于勇、钟益刚、卜璋于、戴超颖、俞哲、吴林军**八位医师被认定为**首届“仁心匠心医师”**。

发布现场，市一医院重症医学科副主任朱英作典型发言。她说，有学者称重症为死亡前的暂停时刻，因为给予医务人员施救的时机十分宝贵和短暂，必须牢牢把握住。所以重症医生需要不断学习，需要十八般武艺样样精通，需要有时刻守在患者床边的毅力；需要时刻关注患者的痛苦、无助与恐惧，及时帮助他们缓解，给予他们力量。重症之路艰辛，但朱英表示将会继续秉持初心，医心医意，一路前行。

市一医院泌尿外科王于勇医生作为医师代表宣读倡议书。他向医师们发出倡议：一要秉承医者仁心，护佑百姓健康。二要坚守白衣初心，扛起医德担当。三要弘扬职业匠心，做到教学相长。铭记党和人民的重托，铭记老一辈医者的传承，以生命赴使命，用大爱护众生，为群众的生命安全保驾护航，为推动杭州市医疗卫生健康事业高质量发展作出新的更大的贡献。

**朱瑾**

杭州市第一人民医院耳鼻咽喉科主任医师、市一医院集团党政办主任。从医34年，他始终把患者放在首位，用丰富经验，以尽量少的费用、最有效且痛苦最小的方法医治每位患者，力求患者在治好病同时少跑、少痛苦，少开支，获得患者广泛信任好评。长期利用业余时间在网络平台耐心解答患者问题。热心医学教育，用行动教育引导学生成长。

**朱英**

杭州市第一人民医院重症医学科主任医师，科室副主任。她热爱重症医学，潜心钻研技术、提升危重症救治能力。2013年学习应用重症超声这可视化手段提升各种休克、呼吸衰竭患者的快速诊断和精准施治水平，对于ECMO患者实施基于重症超声的精细化管理。2015年首先在杭州市开展急危重症超声系列培训、2017年率先牵头全国开展重症超声可视化管理ECMO培训班、2018年在重症医学各类全国年会中作主题报告，在全国重症医学领域具有一定的知名度和影响力。

**王于勇**

杭州市第一人民医院泌尿外科副主任医师。工作中他兢兢业业，曾获医院“医德风尚奖”、多次被评为医院先进工作者、优秀共产党员。积极参与公共卫生知识宣传和健康科普工作，定期参加杭州市医学会“钱塘名医荟”的节目录制。开设抖音号及微信视频号等自媒体宣传阵地。疫情发生以来，我积极参加“党员先锋岗”志愿者活动，在疫情缓解时，积极带领同事复工复产。

**钟益刚**

杭州市第一人民医院心内科副主任医师。2020年初，赴武汉参加抗击新冠疫情工作，作为首批进入隔离病区的医护人员，连续收治45位重症新冠肺炎患者。获得“杭州市抗击新冠肺炎疫情先进个人”称号。在致力共同富裕征程中，长期下沉在基层进行技术帮扶，开设专家门诊服务基层百姓，多次指导救治及转诊疑难、危重患者，受到当地患者好评，《富阳日报》对相关事迹进行报道。

**卜璋于**

杭州市第一人民医院皮肤科副主任医师。他首创的新技术新项目临床应用成果已在国际权威杂志上发表，解决诊疗难点，实现专业领先。目前在“好大夫”皮肤科专业口碑综合排名全国前五，常见病“特应性皮炎”和“尖锐湿疣”排名都位居全国第一。秉持全心全意为病人服务的理念，提升患者满意度，吸引大量来自全国各地的患者慕名就诊。

**戴超颖**

杭州市第一人民医院中医科中西医结合主治医师。擅长中医肿瘤诊治及内科疾病诊治，积极参与中西结合病区多发病和疑难危重症方面的中医诊疗工作。2021年初，积极参加新冠疫苗接种医疗保障任务,2022年春节期间，参加数十次大规模核酸筛查采样工作。2022年3月，驰援上海参加核酸采样工作，在沪期间尽职尽责完成任务。

**俞哲**

杭州市第一人民医院城北院区二病区主任医师。从医二十余年，从事危重型感染性疾病的临床和科研工作，积极参与重症禽流感、H7N9、H5N1、手足口病等新发突发传染病的救治工作。疫情发生后，作为疫情前沿重要科室的医生，积极投身疫情防控一线。在这场没有硝烟的战役中，用实际行动践行救死扶伤的初心。不顾感染风险，每日查房及时了解病人情况，精心治疗，并耐心解释、不断安慰，消除病人的恐惧，增加其战胜疾病的信心。

**吴林军**

杭州市第一人民医院城北院区二病区副主任医师。长期从事临床一线工作，主要为急、慢性创面患者管理及修复重建，熟练植皮、皮瓣的创面外科整复工作，熟练ICU的常规操作，擅长危重压疮及糖尿病足病人的综合管理、抢救及会诊工作。工作中一切以患者为第一，因涉及病种多数为长期慢性创面患者，家庭经济情况堪忧，急病人所急，多次自发为患者捐款治病，治愈创面危重患者数百例。
